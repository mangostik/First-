# Claude Orchestrator Privacy Policy

Last updated: 2026-09-24

Claude Orchestrator is a private engineering-review plugin. It receives the task text and optional repository or pull-request details that the user submits. The service uses those inputs to run the requested review through the configured Claude and OpenAI APIs and may read the specified GitHub repository or pull request when the user provides access.

The service does not sell personal information. Data is shared only with the configured model providers and GitHub when required to perform the requested review. Credentials are stored as deployment secrets and are not returned in tool results. Review inputs and outputs are retained only as long as needed for the configured service operation and troubleshooting, subject to the retention policies of the connected providers.

To request access, correction, or deletion of data associated with a review, contact the plugin operator through the project support page. Do not submit passwords, API keys, or unrelated personal information in a review request.
